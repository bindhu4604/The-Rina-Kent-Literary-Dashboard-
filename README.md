<h2>📊 Project Overview</h2>
<p>
This project presents a complete Power BI dashboard analyzing <b>38 books</b> written by 
dark-romance author <b>Rina Kent</b>, covering sales performance, reader ratings, genre spread, 
series comparisons, and publication trends from <b>2019 to 2026</b>.  
The dashboard is designed with a clean, consistent color theme and a focus on 
<b>data-driven storytelling</b>.
</p>

<h2>🎯 Objectives</h2>
<ul>
  <li>Analyze sales, ratings, and popularity across all books</li>
  <li>Compare performance across major series</li>
  <li>Visualize yearly trends in publication and engagement</li>
  <li>Identify top-performing genres and themes</li>
  <li>Examine correlations such as <b>Ratings vs Sales</b></li>
</ul>

<h2>📌 Key Insights</h2>
<ul>
  <li><b>Dark Romance</b> accounts for <b>39% of all sales</b>.</li>
  <li><b>Royal Elite Series</b> leads with <b>787K+</b> units sold.</li>
  <li><b>18 books</b> reached Best Seller status.</li>
  <li><b>12 books</b> earned <b>4.5⭐+</b> ratings.</li>
  <li>Strong correlation between <b>higher ratings</b> and <b>sales performance</b>.</li>
</ul>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><b>Power BI</b> – Data modeling, DAX, interactive visuals</li>
  <li><b>Excel / CSV</b> – Data preparation</li>
  <li><b>DAX Measures</b> – KPIs & calculations</li>
  <li><b>Custom Theme</b> – UI/UX palette inspired by Dark Romance aesthetics</li>
</ul>

<h2>📈 Dashboard Features</h2>
<ul>
  <li>KPIs for Total Books, Total Sales, Avg Rating, Popularity</li>
  <li>Series-wise and Genre-wise Sales Analysis</li>
  <li>Yearly Reading & Publication Trends</li>
  <li>Slicers for Year, Genre, Series, Performance</li>
  <li><b>Scatter Plot:</b> Ratings vs Sales</li>
  <li>Insight Cards summarizing key takeaways</li>
</ul>
